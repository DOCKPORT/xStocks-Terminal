# xStocks Terminal

A web app that analyzes all xStocks tokenized assets.

`Not partnered with xStocks. This Repo simply uses public API data.`



## Stack
- Python scripting.
- Github actions.
- HTML, CSS, and JavaScript.
- Vercel.
- xStock API v2.
- BQ-MICS (Business Quant Multi-Industry Classification System)
- SEC EDGAR
